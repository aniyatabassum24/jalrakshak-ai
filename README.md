# JalRakshak AI 🌧️

## 1. Problem Statement
AI-powered urban waterlogging risk assessment and early warning system for Warangal, Hanamkonda, and Kazipet, Telangana.

## 2. Solution
Citizens can input local conditions + live rainfall data to get LOW/MEDIUM/HIGH risk with safety recommendations.

## 3. Tech Stack
- Python
- Streamlit for UI
- OpenWeather API for live rainfall data
- Rule-based Risk Scoring

## 4. How to Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
